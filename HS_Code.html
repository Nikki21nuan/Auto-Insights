HS Code完成后还要做什么？

▶
结束动作｜Completed 邮件 → 通知 Costing

HS Code 建好后会收到 JCA 的 Completed 邮件。
收到邮件后，通知 Costing COE_APAC <apaccosting@te.com> costing 团队建 cost。

收到 Completed 邮件→通知 Costing COE_APAC→Costing 建 Cost
